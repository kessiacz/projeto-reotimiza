# Reotimiza Comunicação — Landing Page

Site desenvolvido para a agência **Reotimiza Comunicação**, focado em apresentação de serviços de marketing digital, branding, tráfego pago, social media e produção audiovisual.

---

## Demonstração

🔗 Acesse o site: *reotimiza.vercel.com*  

---

## Sobre o Projeto

O site foi desenvolvido com foco em:

- Apresentação de marca
- Experiência moderna e interativa
- Conversão de leads via WhatsApp
- Portfólio dinâmico com vídeos reais
- Identidade visual forte (dark + neon pink)

A Reotimiza Comunicação é uma agência que atua com:

- Branding & Identidade Visual
- Tráfego Pago (Meta Ads / Google Ads)
- Social Media & Conteúdo
- Produção Audiovisual
- Gestão de Eventos
- Automação & CRM

## Features do Site

### Interface e UX
- Cursor personalizado animado
- Scroll suave entre seções
- Animações de entrada (reveal on scroll)
- Navbar com efeito blur ao scroll
- Layout responsivo (mobile-first)

### Interatividade
- Menu mobile responsivo
- Formulário integrado ao WhatsApp
- Hover effects em cards e serviços
- Carrossel automático na seção "Sobre"
- Vídeos autoplay no portfólio

### Seções do Site
- Hero section com estatísticas
- Marquee animado de serviços
- Sobre a agência
- Serviços detalhados
- Processo de trabalho
- Portfólio com vídeos reais
- CTA chamativo
- Formulário de contato
- Footer completo
